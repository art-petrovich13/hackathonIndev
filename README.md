# FaceDiagnosis — хакатонный проект для компании IndevSolutions

> Веб-приложение для предварительной оценки состояния здоровья по фотографии лица и данным анкеты с возможностью получения рекомендаций, сохранения результатов и записи на медицинские осмотры.

Проект разработан **в рамках хакатона**.

---

## 📌 О проекте

**FaceDiagnosis** — прототип медицинского веб-сервиса, который объединяет предварительный анализ состояния пользователя, анкетирование и дальнейшие медицинские сценарии в одном интерфейсе.

Основная идея проекта — предоставить пользователю простой путь:

```text
Фото
 ↓
Анализ лица
 ↓
Анкета о состоянии здоровья
 ↓
Комплексная оценка
 ↓
Рекомендации
 ↓
Медицинские сценарии
```

Помимо фотообследования, пользователь может записаться на профилактический осмотр или водительскую медицинскую комиссию, а также работать со своими медицинскими документами и талонами.

---

## 🎯 Основная идея

Пользователь начинает с главного экрана и может перейти к фотообследованию.

Для анализа можно:

- сделать фотографию с камеры;
- загрузить готовое изображение.

После загрузки система проверяет наличие лица на фотографии. Если лицо обнаружено, пользователь переходит к многоэтапной анкете о состоянии здоровья.

Анкета учитывает основные сведения о пользователе, хронические заболевания, состояние кожи, травмы, образ жизни, сон, стресс и текущие симптомы.

После заполнения анкеты данные вместе с результатами анализа лица используются для формирования предварительного отчёта.

---

## 🔄 Основной workflow

```text
Главная страница
       ↓
Фото с камеры / загрузка изображения
       ↓
Проверка наличия лица
       ↓
Заполнение анкеты
       ↓
Анализ фотографии + данных анкеты
       ↓
Формирование результата
       ↓
Рекомендации и факторы риска
       ↓
Сохранение результата / PDF
       ↓
Запись к врачу или медицинский осмотр
```

Система также позволяет вернуться к фотообследованию и пройти новый анализ.

---

## 📷 Фотообследование

Основной функциональный блок приложения — анализ фотографии лица.

Пользователь может получить изображение двумя способами:

- через камеру устройства;
- загрузив изображение из файла.

Для работы с камерой используется стандартный браузерный `MediaDevices API`.

После получения фотографии приложение выполняет обнаружение лица с использованием `@vladmandic/face-api`.

На основе facial landmarks рассчитываются различные параметры, включая:

- симметрию лица;
- открытость глаз;
- положение головы;
- некоторые показатели, связанные с напряжением лица.

Если лицо не найдено, пользователь получает уведомление и может повторить фотографирование.

---

## 📝 Анкета здоровья

После успешного обнаружения лица пользователь проходит анкету из нескольких этапов.

Собираются данные о:

- возрасте и поле;
- хронических заболеваниях;
- принимаемых лекарствах;
- аллергиях;
- состоянии кожи;
- чувствительности кожи;
- недавнем воздействии солнца;
- травмах;
- употреблении алкоголя;
- курении;
- уровне стресса;
- качестве сна;
- текущих симптомах;
- длительности симптомов;
- дополнительных комментариях.

Анкета используется как дополнительный источник данных для формирования итоговой оценки.

---

## 🧠 Анализ состояния

После заполнения анкеты приложение объединяет результаты анализа лица и введённые пользователем данные.

Формируется комплексный результат, включающий:

- общий показатель;
- анализ характеристик лица;
- оценку состояния кожи;
- показатели стресса;
- факторы образа жизни;
- потенциальные факторы риска;
- подробное заключение;
- рекомендации;
- рекомендации по обращению к специалистам.

В частности, результат содержит отдельные показатели для состояния глаз, напряжения лица, положения головы, состояния кожи, стресса, сна и образа жизни.

---

## 👨‍⚕️ Рекомендации

На основе полученных данных система формирует рекомендации и может определить, консультация какого специалиста может быть актуальна.

В зависимости от результатов могут формироваться рекомендации обратиться к:

- терапевту;
- дерматологу;
- неврологу;
- сомнологу;
- психологу/психотерапевту;
- гастроэнтерологу или диетологу;
- другим специалистам.

Рекомендации содержат приоритет, причину рекомендации и возможные направления дальнейшего обследования.

> **Важно:** результаты являются предварительной оценкой и не заменяют профессиональную медицинскую диагностику. Сам интерфейс проекта также предупреждает пользователя о необходимости обратиться к квалифицированному врачу для получения точного диагноза.

---

## 📄 Сохранение результатов

Результаты обследования можно подготовить в виде PDF-документа.

Для генерации PDF используются:

- `html2canvas`;
- `jsPDF`.

Это позволяет сохранить результаты анализа и использовать их как отдельный отчёт.

---

## 👤 Авторизация и профиль

В приложении предусмотрена регистрация и авторизация пользователя по email и паролю.

Для управления авторизацией используется **Supabase Auth**.

Авторизованный пользователь получает доступ к профилю, где предусмотрены:

- медицинские заключения;
- загруженные PDF-документы;
- медицинские талоны;
- переход к записи на приём;
- запуск нового фотообследования.

Также реализована защищённая маршрутизация для страниц, доступных только авторизованным пользователям.

---

## 🏥 Запись на медицинские осмотры

Помимо диагностики, проект содержит отдельные сценарии для записи на медицинские услуги.

### Профилактический осмотр

Пользователь может:

1. выбрать поликлинику;
2. посмотреть информацию о ней;
3. при необходимости открыть карту;
4. выбрать врачей и доступное время;
5. заполнить данные для записи;
6. оформить запись;
7. получить талон в PDF.

Сценарий предусматривает комплексный профилактический осмотр с несколькими специалистами.

### Водительская медицинская комиссия

Отдельный сценарий предназначен для прохождения водительской комиссии.

Workflow аналогичен:

```text
Выбор медицинского центра
        ↓
Выбор специалистов
        ↓
Выбор времени
        ↓
Ввод данных
        ↓
Оформление записи
        ↓
Формирование справки / PDF
```

В интерфейсе также отображается расписание выбранных специалистов и информация о комиссии.

---

## 🎫 Медицинские талоны

В профиле пользователь может просматривать свои записи к врачам.

Для талонов предусмотрены статусы и основная информация:

- врач;
- специальность;
- дата;
- время;
- кабинет;
- поликлиника;
- статус записи.

Талон можно сохранить в PDF или отправить на печать.

---

## 🗺️ Выбор медицинского учреждения

При записи на профилактический осмотр предусмотрен выбор поликлиники как из списка, так и через карту.

Для отображения карты используется отдельный компонент `YandexMapModal`.

Данные медицинских учреждений, врачей и доступных записей в текущей версии проекта представлены в виде демонстрационных данных.

## 🚀 Запуск проекта

### Требования

- Node.js
- npm
- современный браузер с поддержкой камеры

### Установка

```bash
git clone https://github.com/art-petrovich13/hackathonIndev.git
cd hackathonIndev/Hackathon.UI
npm install
```

### Переменные окружения

Для авторизации через Supabase необходимо создать `.env`:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Supabase-клиент получает эти значения через `import.meta.env`.

### Запуск в режиме разработки

```bash
npm run dev
```

### Production-сборка

```bash
npm run build
```

### Предпросмотр production-сборки

```bash
npm run preview
```

### Проверка линтером

```bash
npm run lint
```

Скрипты запуска, сборки, lint и preview определены в `package.json`.

## 📌 Текущий статус

Проект представляет собой **хакатонный прототип** медицинского веб-сервиса.

Основной пользовательский сценарий реализован от получения фотографии и заполнения анкеты до формирования предварительного результата и перехода к медицинским услугам.

В проекте также реализованы авторизация, профиль пользователя, работа с медицинскими документами, талоны, генерация PDF и сценарии записи на профилактический осмотр и водительскую комиссию.

При этом часть данных и отдельных сценариев в текущей версии работает в демонстрационном режиме на основе подготовленных данных, поэтому проект следует рассматривать именно как прототип, а не как готовую медицинскую информационную систему.

## 🏆 Хакатонный проект

**FaceDiagnosis** объединяет в одном веб-приложении несколько связанных сценариев:

**фотообследование → анкета → предварительный анализ → рекомендации → медицинские документы → запись к врачу.**

Проект демонстрирует использование **React, TypeScript, Computer Vision, Supabase, PDF-генерации и клиентской работы с камерой** для создания единого пользовательского медицинского сервиса.
